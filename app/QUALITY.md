# App QUALITY

Windows / デスクトップアプリで機械検査しやすい共通品質を定めます。製品固有でしか意味を持たない項目は、製品側の設定または正本へ置きます。

## FAILにできる項目

- 製品が宣言した必須ファイルまたは必須アイコンがない。
- Python sourceを構文解析できない。
- 製品が宣言したbuild / Windows metadata文字列がない。
- 利用者向け対象に禁止クレジットがある。
- profile設定が不正で、意図した検査を実行できない。

## WARNにする項目

- UI文字列に内部エラー名らしき表現がある。
- 強い警告、表記揺れ、不親切な可能性がある表現がある。
- 検査対象が宣言されず、確認範囲が限定されている。

`WARN` は文脈確認の入口であり、自動修正の命令ではありません。

## 負担の上限

- profileに無関係な検査は実行しない。
- 小規模アプリへ大規模アプリの構造を強制しない。
- build、実機GUI、署名、外部配布の確認を、source検査のPASSで代替しない。
- 製品固有要件は `peakheadz_quality.json` で宣言し、共通checkerへ製品名をhard-codeしない。
