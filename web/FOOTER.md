# Web FOOTER

footerの文面と導線は製品固有です。PEAKHEADZ全サイトへ一つのfooterを強制しません。

- 製品正本で確定したブランド、著作権、法務、連絡、主要導線を維持する。
- 作者名やプロフィール導線を全製品へ一律追加しない。
- 禁止クレジットは表示しない。
- footerを新しい営業面や横断navigationへ作り替えない。
- 機械検査する文面は製品設定で宣言し、共通checkerへ製品名をhard-codeしない。

## 著作権表示

菊田幸彦に権利が帰属する製品の標準行は次とする。

```text
© {year} Yukihiko Kikuta · PEAKHEADZ
```

- `·` はU+00B7。`・`、`/`、`|`、括弧、`by`、`All rights reserved.` を標準行へ追加しない。
- 氏名と屋号は非リンク。click handler、`role="link"`、独立した計測属性を付けない。
- 表示年は製品正本で確認した範囲から決め、初回公開年と終了年が同じなら一度だけ表示する。現在年を自動で全製品へ適用しない。
- 第三者素材、共同制作、法人帰属、権利移転、権利者不明の場合は個別確認とする。統一表記で権利帰属を変更したり、第三者通知を削除したりしない。
