# BRANDING

PEAKHEADZ製品の作者・著作権・製品内クレジットに関する共通方針です。既存製品で確定している表記がある場合は、その正本を優先します。

## 基本名称

- Author: `Yukihiko Kikuta`
- Brand / CompanyName: `PEAKHEADZ`
- Windows metadataのCopyright基本形: `© Yukihiko Kikuta / PEAKHEADZ`

製品内クレジットは、製品固有正本に確定表記があればそれを使います。作者名、ブランド名、著作権表記を別々の場所で推測して増やしません。

## 利用者向け作者クレジットに使わない表現

- `vibe coding` / `Vibe-Coded`
- `AI-generated`
- `Made with AI`
- `Codex`

内部の開発記録でツール名を記録することと、利用者向け作者クレジットへ表示することは分けます。
